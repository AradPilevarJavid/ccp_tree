# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue or pull
request. Use GitHub's private vulnerability reporting for this repository:

<https://github.com/AradPilevarJavid/ccp_tree/security/advisories/new>

If private vulnerability reporting is unavailable, contact the maintainers
through a private channel on GitHub and include "ccp security report" in the
message.

Include the affected version or commit, operating system, reproduction steps,
and an assessment of the impact. Please avoid sending credentials or other
real secrets; use safe test values instead.

The maintainers will acknowledge reports as soon as practical, investigate the
issue, and coordinate a fix and disclosure timeline with the reporter.

## Supported versions

Security fixes are developed against the latest `master` branch and the latest
published release. Older releases may not receive security fixes.
